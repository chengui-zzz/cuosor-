# Caret

Cursor 开机动画的一组网页方案。打开仓库根目录的 `index.html` 就能看，不需要安装依赖，也不需要构建。

五版短片各做一个动作，大约 4.6 到 5.2 秒。另外三稿更长，用来试鼠标交互。

## 版本

| 名称 | 时长 | 入口 |
| --- | --- | --- |
| 快门 | 4.6s | `versions/index.html?v=shutter` |
| 一击 | 4.8s | `versions/index.html?v=strike` |
| 一个词 | 5.2s | `versions/index.html?v=word` |
| 落点 | 4.8s | `versions/index.html?v=drop` |
| 翻面 | 5.2s | `versions/index.html?v=flip` |
| 光标补全 | 7.8s | `demo/index.html` |
| 光圈 | 9.6s | `demo-2/index.html` |
| 坍缩 | 10.4s | `demo-3/index.html` |

短片里空格暂停，Esc 跳到结尾。落点那一版，立方体落在鼠标所在的位置。

## 说明

画面里的等轴立方体是这组方案自己画的标记，不是 Cursor 的官方标志。底色 `#14120B`、字色 `#EDECEC`、强调色 `#F54E00` 取自 cursor.com 公开配色。字体用系统里的 Bahnschrift 和微软雅黑，不从网上加载。

`产品需求.md`、`产品架构.md`、`目前进度.md` 记录的是更早一稿的方案和后续接入 Cursor 的设想。这几份网页目前只在浏览器里播放。
